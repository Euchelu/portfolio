# Sistema de Internacionalización (ES/EN)

## Cómo funciona

1. `src/i18n/translations.ts` contiene un objeto con dos claves: `es` y `en`, cada una con todos los textos del sitio organizados por sección.
2. `src/context/LanguageContext.tsx` expone `{ lang, toggleLang, tr }` a través de un Context.
3. El toggle ES/EN en la Navbar llama a `toggleLang()`.
4. Cada componente usa `const { tr } = useLanguage()` para acceder a los textos del idioma activo.

## Cambiar un texto existente

Editar `src/i18n/translations.ts`:

```ts
// Ejemplo: cambiar el badge del Hero
hero: {
  badge: 'Disponible para nuevas oportunidades',   // ES
  ...
}
// y en en:
hero: {
  badge: 'Open to new opportunities',              // EN
  ...
}
```

## Añadir un nuevo idioma

1. En `translations.ts`, extender el tipo `Lang`:
```ts
export type Lang = 'es' | 'en' | 'fr'
```

2. Añadir la clave `fr` con todos los textos traducidos (misma estructura que `es`/`en`).

3. En `LanguageContext.tsx`, actualizar `toggleLang` para ciclar entre los tres idiomas:
```ts
const toggleLang = () => setLang((l) => l === 'es' ? 'en' : l === 'en' ? 'fr' : 'es')
```

4. En `Navbar.tsx`, actualizar el label del botón para mostrar el siguiente idioma.

## Textos que NO están en las traducciones

- Nombres propios: `José Ángel` (aparece igual en ambos idiomas)
- URLs de GitHub, LinkedIn, email
- Tags técnicos de proyectos: `Python`, `Docker`, `FastAPI`...
- Años en el timeline de experiencia
